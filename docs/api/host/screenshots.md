# Screenshots

`window.host`

## `takeScreenshot(Object<{ videoCompositionId?: string }>, ResultCallback<success>)`

Take a screenshot of the specified *videoCompositionId*. If *videoCompositionId* is not specified or is not a string (i.e. null, undefined, number, etc.), the default OBS video composition will be used as input.

**Available since API version 6.0**
