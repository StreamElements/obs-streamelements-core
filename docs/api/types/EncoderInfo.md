# EncoderInfo

| **Property** | **Type** | **Description** |
| --- | --- | --- |
| id | string | Video encoder Id |
| codec | string | CODEC |
| name | string | Display name |
| type | string | ‘audio’ or ‘video’ |
| isDeprecated | boolean | **Read-only**. True if the encoder is marked as deprecated.<br>**API 6.2+** |
