# InvokeInfo

| **Property** | **Type** | **Description** |
| --- | --- | --- |
| invoke | string | API method to invoke.<br>The value of this field corresponds to one of API method names described in this document.<br>Examples:<br>“showModalDialog”, “showCentralWidget”, “addDockingWidget”, “openPopupWindow”, etc. |
| invokeArgs | array | Arguments to the API method described by *invoke* as described by the API call documentation in this document. |
