# SystemMemoryUsageInfo

| **Property** | **Type** | **Description** |
| --- | --- | --- |
| units | string | Specifies the units which the numbers below represent. |
| memoryUsedPercentage | number | % of memory in use |
| totalPhysicalMemory | number | Total available physical memory |
| freePhysicalMemory | number | Free physical memory |
| totalVirtualMemory | number | Total available virtual memory |
| freeVirtualMemory | number | Free virtual memory |
| freeExtendedVirtualMemory | number | Free extended virtual memory |
| totalPageFileSize | number | Page file size |
| freePageFileSize | number | Free space in page file |
